# Verification

This is a concise summary of how the project is verified. The detailed logs live outside the
repository.

| Check | Command | Expectation |
| --- | --- | --- |
| Tests | `python -m pytest -q` | all pass |
| Lint | `ruff check .` | no findings |
| Format | `ruff format --check .` | no files would change |
| Art | `python art/generate_art.py --check` | committed art matches the generator |
| Build | `python -m build` | wheel and sdist built (outputs git-ignored) |
| End to end | `scripts/e2e-smoke.sh` | fresh venv installs the wheel and the offline flow passes |
| Secrets | `scripts/scan-secrets.sh` | exit 0, no findings beyond the audited baseline |

## End-to-end smoke

`scripts/e2e-smoke.sh` builds a wheel and sdist into a temporary directory, creates a fresh
virtual environment, installs the wheel and then:

1. runs `mascot-wardrobe --help`;
2. generates from `examples/mascot.png` twice and compares manifest and asset hashes and mtimes;
3. selects at 3, 10, 17, 21, 28 and 35 C (one per BR category) and at 77 F (warm);
4. runs `demo --channel telegram` twice and checks the second run is `unchanged` with identical
   hashes and mtimes.

It never passes `--live-weather`, so it uses no network for weather. Set
`MASCOT_WARDROBE_EVIDENCE_DIR` to keep the build outputs and working files; by default a
temporary directory is used.

## Secret scanning

`scripts/scan-secrets.sh` runs `detect-secrets-hook --baseline .secrets.baseline` over tracked
files plus untracked files that are not ignored. The hook exits non-zero on new findings. The
baseline was generated by detect-secrets and audited: it contains no real secrets. A sanitized
report can be written to a path passed as the first argument.

## Test-driven development

New or changed behavior was written test first, with the failing and passing runs saved outside
the repository. Traceability from each acceptance criterion to tests is in `traceability.md`.
